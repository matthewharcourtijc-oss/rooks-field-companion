Navigation — OS symbols, bearings — check current map + BGS tool — no prediction
  • OS symbols UK: Brown contours, blue water, green woodland, black manmade. Close contours steep. V points uphill along streams. Paper OS map primary.
  • Bearings: Map to ground align north. Edge from you to target, rotate bezel north, red in shed. Handrail, catching, aiming off, attack points at night. Seek qualified training for night navigation.
  • Magnetic declination — substantiable only: Magnetic north differs from true north and grid north and changes over time. The amount varies across UK. Check your current Ordnance Survey map for the declination information printed on it. Use British Geological Survey tool which calculates angle between grid north and magnetic north for your location. Do not rely on this aide-memoire for declination value — check map + BGS at time of use.
  • Removed in v0.3.7: Previous versions included specific prediction about triple alignment leaving England at triple-alignment location
First Aid — NHS sources only — aide-memoire only — stripped to substantiable
Call 999 or 112. Police then Mountain Rescue if hills. Grid + What3Words + what happened + casualties. Not training. Check NHS and MREW sources listed below.
  • Hypothermia — NHS: Dangerous drop below 35C, medical emergency, Go to A&E or call 999. See NHS page for full guidance. Shelter, insulation from ground, dry clothes, gentle handling. Warm non-alcoholic drink + sugary food ONLY if fully awake and can swallow safely. Usually treated in hospital.
  • Heat exhaustion vs Heatstroke — NHS 30-min rule: Heat exhaustion does NOT usually need emergency help IF you can cool down within 30 minutes. If it turns into heatstroke, treat as emergency. See NHS page for signs. If still hot after 30min cooling or temp above 40C or confusion, call 999.
  • Anaphylaxis — NHS positioning: Lie flat legs raised if possible. If breathing difficult allow to raise shoulders or sit up slowly. If pregnant lie on left side. Do NOT allow to stand or walk at any time even if feeling better due to cardiac arrest risk. Avoid sudden posture change. If vomiting or unconscious breathing recovery position. Adrenaline pen if prescribed — auto-injection pen — stay till ambulance, second dose after 5min if no improvement. See NHS pages.
  • Distress — MREW: Both torch and whistle can be used to signal for help: Six good long blasts in a minute. Stop for one minute. Repeat. Continue until someone reaches you and do not stop because you hear a reply. International: six blasts or six flashes in one minute then minute pause then repeat. Full guidance on Mountain Rescue England and Wales site.

Transaction architecture & write-path inventory

All cooperating writes require navigator.locks exclusive lock "harcom-storage-transaction-v1". If Web Locks are unavailable, writes and destructive operations fail closed. transactionWrite: exact raw set/read-back; durable harcom_recovery_* copy before overwrite; conditional rollback only when current raw still equals the observed attempted-write value; primary-key stale check against lastKnownRaw. transactionDelete: durable raw copy, verified deletion and conditional rollback. Legacy migration holds one exclusive Web Lock across snapshot, verified recovery copies, durable journal, primary write, snapshot-checked cleanup, final verification and journal close; startup recovery is idempotent and refuses to overwrite unexpected values. lastKnownRaw and arrays commit only after complete success.

Write-path inventory: task create/complete/delete; note create/delete; log create/delete; import; safety restore; legacy migration and legacy-key cleanup; corrupt/malformed raw preservation; manual-backup marker; persistence canary/test records; safety-backup deletion; Clear All snapshot and deletion/rollback. All primary-record mutations use commitCombined (transactionWrite + validation + deferred lastKnownRaw commit); other mutations use transactionWrite/transactionDelete/conditionalRollback or the lock-held Clear All transaction. Export and clipboard are read-only. Validation-only actions are read-only.

Executable simulated failure harness: runTransactionFailureTests() — isolated in-memory storage only; it does not touch saved user data. Simulations are not browser or Android certification.

Single file, no external deps, no AI keys. Primary key: harcom_data (single atomic record). Legacy migration uses a durable harcom_migration_journal_v1 with exact raw snapshots and recovery references; interrupted migration is recovered under one exclusive lock before normal loading. Keys: harcom_data, harcom_backup_last, harcom_persist_test_v3, harcom_persist_canary, harcom_safety_*, harcom_corrupt_*.
